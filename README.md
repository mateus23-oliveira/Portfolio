# Portfólio — Mateus Oliveira

Portfólio pessoal desenvolvido com Next.js, React e CSS responsivo, com foco em desenvolvimento de software e evolução em inteligência artificial.

## Requisitos
- Node.js compatível com a versão do Next.js usada neste projeto
- npm

## Executar localmente

```bash
npm install
npm run dev
```

Abra http://localhost:3000 no navegador.

## Gerar build de produção

```bash
npm run build
npm start
```

## Antes de publicar

- Atualize os links dos cards para os repositórios exatos de cada projeto.
- Confirme se as descrições refletem sua contribuição real e o estado atual de cada projeto.
- Adicione screenshots e instruções de execução aos READMEs dos repositórios.
- Substitua o link genérico do LinkedIn pelo seu perfil público.
- Mantenha as ideias de IA marcadas como propostas/em desenvolvimento até haver uma implementação funcional.

## Deploy na Vercel

Importe o repositório Git na Vercel e mantenha as configurações padrão de Next.js. Para novas versões, faça commit e push para a branch conectada ao projeto; a Vercel fará um novo deploy automaticamente.
